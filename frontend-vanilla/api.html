API Documentation

REST API tích hợp TempMail. Tất cả endpoint yêu cầu Authorization: Bearer <JWT> trừ /open_api/settings. JWT nhận được từ POST /api/new_address.

Backend chạy trên Cloudflare Workers + D1. Frontend vanilla HTML/JS gọi trực tiếp các endpoint dưới đây. Mỗi address khi tạo sẽ trả về jwt dùng cho các request tiếp theo (Bearer token).

1. Lấy danh sách domain & settings

GET/open_api/settings

Trả về cấu hình service + danh sách domain khả dụng. Không cần auth.

RESPONSE
{ "title": "...", "domains": ["miraclelab.online"], "defaultDomains": ["miraclelab.online"], "prefix": "tmp", "needAuth": false, "enableUserCreateEmail": true, "enableUserDeleteEmail": true, "minAddressLen": 1, "maxAddressLen": 30, ... }

2. Tạo địa chỉ email tạm thời

POST/api/new_address

Tạo một địa chỉ email mới. Trả về JWT dùng cho các request tiếp theo.

PARAMETERS (body, JSON)
Tham sốKiểuMô tả
namestring, optionalUsername tuỳ chỉnh. Nếu không gửi, server tự tạo random (kèm prefix nếu có). Tối đa 30 ký tự.
domainstring, optionalDomain cụ thể (phải nằm trong danh sách domain khả dụng). Mặc định: domain đầu tiên.
RESPONSE
{ "jwt": "eyJhbGc...", "address": "tmpjohndoe@miraclelab.online", "password": null, "address_id": 42 }

3. Lấy thông tin settings của address

GET/api/settings

Trả về thông tin của address hiện tại (dựa trên JWT) + send balance.

HEADERS
Authorization: Bearer <JWT>
RESPONSE
{ "address": "tmpjohndoe@miraclelab.online", "send_balance": 0 }

4. Xem danh sách email trong hộp thư

GET/api/parsed_mails?limit=20&offset=0

Lấy danh sách email đã nhận (đã parse sẵn: sender, subject, text, html).

QUERY PARAMS
Tham sốKiểuMô tả
limitnumber, default 20Số email tối đa trả về
offsetnumber, default 0Phân trang (luôn gửi 0 cho trang đầu)
RESPONSE
{ "results": [ { "id": 1, "address": "tmpjohndoe@miraclelab.online", "sender": "noreply@github.com", "subject": "Verify your email", "text": "...", "html": "...", "attachments": [], "created_at": "2026-08-17 14:30:00" } ], "count": 1 }

5. Đọc nội dung đầy đủ một email

GET/api/parsed_mail/:id

Lấy nội dung đầy đủ (text + html) của email theo id.

RESPONSE
{ "id": 1, "address": "tmpjohndoe@miraclelab.online", "sender": "noreply@github.com", "subject": "Verify your email", "text": "Click here to verify...", "html": "<p>Click <a href='...'>here</a> to verify</p>", "attachments": [], "created_at": "2026-08-17 14:30:00" }

6. Xóa một email

DELETE/api/mails/:id

Xóa email cụ thể theo id. Cần ENABLE_USER_DELETE_EMAIL=true trên worker.

RESPONSE
{ "success": true }

7. Xóa toàn bộ address (hộp thư + địa chỉ)

DELETE/api/delete_address

Xóa address hiện tại (theo JWT) và toàn bộ email trong hộp thư. Hành động không thể hoàn tác.

RESPONSE
{ "success": true }

Ví dụ dùng curl với BASE_URL = URL service của bạn.

1. Lấy danh sách domain
curl -s "BASE_URL/open_api/settings" | jq '.domains, .defaultDomains'
2. Tạo email ngẫu nhiên
curl -s -X POST "BASE_URL/api/new_address" -H "Content-Type: application/json" -d '{}' | jq
3. Tạo email với username tuỳ chỉnh
curl -s -X POST "BASE_URL/api/new_address" -H "Content-Type: application/json" -d '{"name":"myname","domain":"miraclelab.online"}' | tee /tmp/result.json # Lưu JWT JWT=$(jq -r .jwt /tmp/result.json) echo "Address: $(jq -r .address /tmp/result.json)"
4. Xem hộp thư (cần JWT)
curl -s "BASE_URL/api/parsed_mails?limit=20&offset=0" -H "Authorization: Bearer $JWT" | jq '.results | length'
5. Đọc một email
curl -s "BASE_URL/api/parsed_mail/1" -H "Authorization: Bearer $JWT" | jq '{sender, subject, text}'
6. Xoá một email
curl -s -X DELETE "BASE_URL/api/mails/1" -H "Authorization: Bearer $JWT" | jq

Hầu hết endpoint trả về JSON. Lỗi thường là HTTP 4xx/5xx với body text hoặc JSON dạng { "error": "..." }.

CÁC MÃ LỖI PHỔ BIẾN
HTTP StatusNguyên nhânCách xử lý
400Body JSON thiếu/sai, hoặc address không tồn tại trong DBKiểm tra payload, đảm bảo address_id tồn tại
401JWT hết hạn / sai format / không gửi kèm BearerTạo lại address mới, lưu JWT mới
403Tính năng bị tắt (vd: delete email khi ENABLE_USER_DELETE_EMAIL=false), Turnstile failKiểm tra config worker
429Rate limit (chỉ áp dụng /api/new_address, /api/send_mail)Đợi 60s rồi retry, hoặc giảm tần suất
500Lỗi server (D1 down, parser fail, etc.)Retry sau vài giây, check Worker logs
⚠️ Email tạm thời sẽ tự động bị xóa sau 3 ngày kể từ khi tạo (cleanup job chạy lúc 0:00 UTC hàng ngày qua cron trigger).
ℹ️ Rate limit: 10 request / 60 giây cho mỗi IP tại /api/new_address và /api/send_mail. Các endpoint khác chưa giới hạn.
✅ Không cần đăng ký / API key. Tạo address là dùng được ngay. Mỗi address là 1 session độc lập với JWT riêng.

Hệ thống chạy trên Cloudflare Workers + D1 — đảm bảo tốc độ cao và độ trễ thấp trên toàn cầu. Email được xử lý qua Cloudflare Email Routing (wildcard *@miraclelab.online → worker) và lưu trữ tạm trong D1 trước khi tự động dọn dẹp.
